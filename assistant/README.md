# Личный ассистент в Telegram

Личный чат с ИИ-ассистентом. В течение дня вы наговариваете голосовые: задачи, идеи, вопросы, планы,
мечты. Ассистент расшифровывает их, раскладывает по полочкам (задачи, напоминания, заметки, решения),
строит планы на день, неделю и месяц, напоминает вовремя и может отвечать голосом.

Работает на Claude (Anthropic API). Распознавание речи — Whisper (Groq или OpenAI), озвучка — edge-tts (голоса Microsoft), а запасной вариант — Google TTS.
Все данные хранятся в одном файле SQLite на вашем сервере.

## Что умеет

- **Голос → структура.** Одно голосовое разбирается на части: дело попадает в задачи, конкретное время —
  в напоминания, идея, мечта или цель — в заметки, развилка — в решения, новый факт о вас — в профиль.
  В ответ приходит короткое подтверждение, что записано.
- **Напоминания** — разовые и повторяющиеся (cron), с кнопками «Готово», «+15 мин», «+1 час», «Завтра».
- **Утренний брифинг** (07:00): три главные задачи, дела со временем, решения с подходящим сроком.
  Приходит текстом и голосом.
- **Вечерний разбор** (21:30): что сделано, что перенести, черновик плана на завтра.
- **Недельный обзор** (вс 20:00) и **план на месяц** (1-го числа).
- **Долгая память**: дословный журнал всего, что вы говорили, плюс ночное сжатие в итоги дня, недели
  и месяца. Поиск по смыслу: «что я говорил про рекламу в сентябре?».
- **Помощь с решениями**: обратимое решение или нет, срок, критерий «данных достаточно», вариант
  по умолчанию. Бот напомнит, когда срок подойдёт.
- **Фото и PDF**: накладная, скрин переписки, документ — бот разберёт и сохранит важное.
- **Голосовые ответы**: `/voice auto` (голосом на голосовые), `on` или `off`. Если сервис Microsoft
  не отвечает, бот сам переключается на Google. Проверить озвучку — `/voicetest`.
- **Контроль расходов**: `/stats` показывает траты за месяц. При достижении `MONTHLY_BUDGET_USD` бот
  перестаёт вызывать Claude, но продолжает записывать сообщения в журнал.
- **Бэкап**: `/export` присылает всю память в Markdown и файл базы.

## Как устроено

```
Голосовое ─► Whisper (Groq) ─► текст ─┐
Текст / фото / PDF ───────────────────┤
                                      ▼
                  ┌──────── журнал (дословно, SQLite + FTS5) ◄── ночное сжатие:
                  │                                             день → неделя → месяц
                  ▼
  Claude + 16 инструментов: задачи, напоминания, заметки, решения, поиск по памяти, профиль
                  │
                  ▼
        ответ текстом (HTML) + голосом (edge-tts → OGG/Opus)

Планировщик (каждые 20 с): напоминания, брифинг, разбор, обзоры, ночное сжатие
```

Каждый запрос к Claude собирается из четырёх частей:
1. **Системный промпт и инструменты.** Не меняются между запросами, поэтому кешируются и стоят ~10% цены.
2. **Ядро памяти** — профиль владельца до 4000 символов. Ассистент сам переписывает его, когда узнаёт
   новый устойчивый факт.
3. **Последние 30 сообщений** дословно.
4. **Снимок «что сейчас»**: дата и время, просроченные задачи, задачи на сегодня и неделю, ближайшие
   напоминания, открытые решения.

Всё более старое ассистент находит инструментом `search_memory`: это полнотекстовый поиск по журналу,
заметкам и итогам с учётом русских окончаний.

### Какие идеи взяты из сильных open-source проектов

| Идея | Откуда |
|---|---|
| Сначала дословный журнал, сжатие потом. Иерархия «день → неделя → месяц». Маленькое «ядро памяти» в каждом запросе. Факты переписываются, а не дописываются | [smixs/iva](https://github.com/smixs/iva) |
| Память в SQLite с полнотекстовым поиском FTS5 вместо отдельной векторной БД. Встроенный планировщик с доставкой в мессенджер | [Hermes Agent (Nous Research)](https://www.datacamp.com/tutorial/hermes-agent) |
| Белый список владельца. Сообщения в очереди, пока агент занят. Защита в коде, а не только в промпте | [linuz90/claude-telegram-bot](https://github.com/linuz90/claude-telegram-bot) |
| Пересланное и распознанное — это данные, а не инструкции (защита от prompt injection) | iva, [OpenClaw](https://openalternative.co/alternatives/openclaw) (у последнего это слабое место) |
| Голосовые напоминания и проекты через aiogram | [baimukhanalan/reminder-bot](https://github.com/baimukhanalan/reminder-bot) |

Почему не взять готовый OpenClaw или Hermes:
- **Безопасность.** Это универсальные агенты с доступом к компьютеру; у OpenClaw известны проблемы
  с безопасностью.
- **Стоимость и сложность.** Их тяжелее и дороже содержать.
- **Нет нужного сценария.** В них нет «голосовой дневник → план дня → решения с дедлайнами».

Здесь около 2300 строк понятного кода на Python, который легко менять под себя.

## Быстрый старт на своём компьютере

Бот работает через long polling, поэтому не нужны ни домен, ни открытый порт, ни сервер. Работает,
пока включён компьютер и открыто окно бота.

1. **Создайте бота.** В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Получите ключи:**
   - Claude: [console.anthropic.com](https://console.anthropic.com) → API Keys. В разделе Limits
     **поставьте месячный лимит**, например $30.
   - Распознавание речи: [console.groq.com/keys](https://console.groq.com/keys).
3. **Установите Python 3.10+.**
   - Windows: [python.org](https://www.python.org/downloads/); при установке отметьте «Add python.exe to PATH».
   - macOS: Python обычно уже есть (`python3 --version`), иначе `brew install python`.
4. **Скачайте проект:** на GitHub нажмите Code → Download ZIP и распакуйте.
5. **Запустите** из папки `assistant`:
   - Windows — двойной клик по `start.bat`;
   - macOS / Linux — `./start.sh` в терминале.

   При первом запуске мастер спросит токен, ключи, модель и лимит расходов, создаст `.env` и шаблон
   профиля `data/profile.md`. Заполните профиль: бот прочитает его при следующем запуске.
6. **Узнайте свой ID.** Если вы не указали OWNER_ID, напишите боту что угодно — он ответит вашим
   Telegram ID. Впишите его в `.env` как `OWNER_ID=...`, закройте окно и запустите снова.
7. Готово: отправьте первое голосовое.

Чтобы бот не «засыпал» вместе с компьютером:
- **Windows:** Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда» (при питании от сети).
- **macOS:** `start.sh` сам не даёт Mac уснуть, пока бот запущен (через `caffeinate`).

Напоминания, пропущенные во время сна или выключения, придут после запуска с пометкой о задержке.
Утренний брифинг бот догонит, если запустится в течение 3 часов после назначенного времени.

Голосовые ответы работают и без `ffmpeg`, но с ним они приходят как настоящие голосовые с волной.
Установка: Windows — `winget install Gyan.FFmpeg`, macOS — `brew install ffmpeg`.

### Если у вас Telegram Premium

- Premium сам расшифровывает голосовые в приложении. Бот всё равно расшифровывает их своим Whisper
  и показывает, что *он* услышал, — так видно ошибки распознавания. Если дубль мешает, отключите его
  командой `/voice transcript off`.
- В Premium входит **Telegram Business → Чат-боты**: бота можно подключить к вашему личному аккаунту,
  чтобы он видел выбранные переписки (например, с поставщиками) и сам вытаскивал из них задачи.
  Через это же подключение бот может присылать нативные чек-листы Telegram (`sendChecklist`), где пункты
  отмечаются галочкой. Это следующий этап. Через бота пойдут сообщения других людей, поэтому включать
  стоит только для выбранных чатов.

### Обновление на Windows

Закройте окно бота и запустите `update.bat`: он скачает свежий код с GitHub, а `.env` и папку `data\`
не тронет. Потом снова `start.bat`.

## Постоянная работа на сервере (VPS)

Подойдёт любой VPS с 1 ГБ RAM (Hetzner CX22, PS.kz и т.п., ~$5/мес).

```bash
git clone <repo> && cd <repo>/assistant
cp .env.example .env && nano .env
mkdir -p data && cp profile.example.md data/profile.md && nano data/profile.md
docker compose up -d --build
docker compose logs -f        # логи
```

База, профиль и всё остальное лежат в `assistant/data/` на хосте. Делайте бэкап этой папки или
периодически вызывайте `/export`.

## Сколько стоит

Это оценка для активного дня: 30 голосовых по ~1 минуте, ~2 обращения к Claude на сообщение,
4 автозапуска. Реальные цифры показывает `/stats`.

| Модель (`CLAUDE_MODEL`) | Claude в месяц | + речь (Groq) | + VPS |
|---|---|---|---|
| `claude-opus-5-5` — лучшее качество разбора и планов | ~$60–90 | ~$2 | ~$5 |
| `claude-sonnet-5-5` | ~$30–45 | ~$2 | ~$5 |
| `claude-haiku-5-5` — дёшево, но проще | ~$2–4 | ~$2 | ~$5 |

Как снизить расходы, не меняя модель:
- `CHAT_EFFORT=low` — меньше размышлений в обычном чате;
- `HISTORY_MESSAGES=15` — короче контекст.

Озвучка (edge-tts / Google TTS) бесплатная. Живой голос OpenAI — по желанию: впишите `OPENAI_API_KEY`
в `.env`, это ~$0.015 за минуту речи (при 10 минутах голосовых ответов в день ≈ $4–5/мес).

## Команды

| Команда | Что делает |
|---|---|
| `/today` | Задачи и напоминания на сегодня (мгновенно, без ИИ) |
| `/plan` | Собрать план дня с ИИ |
| `/tasks` | Все открытые задачи по сферам |
| `/reminders` | Ближайшие напоминания |
| `/ideas` | Идеи, мечты, цели |
| `/review` | Вечерний разбор прямо сейчас |
| `/week` | Недельный обзор прямо сейчас |
| `/memory` | Что ассистент знает о вас (ядро памяти) |
| `/voice auto\|on\|off` | Голосовые ответы; `/voice transcript on\|off` — показ расшифровки |
| `/voicetest` | Проверить сервисы озвучки и прислать образец голоса |
| `/stats` | Расходы за месяц |
| `/export` | Бэкап памяти |

Всё остальное — обычными словами или голосом: «перенеси созвон на пятницу», «закрой задачу про оплату»,
«что у меня по целям на этот месяц?».

## Приватность и безопасность

- Бот отвечает только `OWNER_ID`, остальным молчит. Если `OWNER_ID` не задан, бот работает в режиме
  настройки и только показывает ID.
- Ваши данные хранятся в `data/assistant.db` на вашем сервере. Текст сообщений уходит в Anthropic API,
  аудио — в Groq/OpenAI для расшифровки.
- `.env`, `data/` и профиль в git не попадают (см. `.gitignore`). **Если репозиторий публичный, не
  коммитьте туда личные данные.** Надёжнее сделать репозиторий приватным.
- edge-tts и Google TTS — неофициальные бесплатные сервисы. Если оба недоступны, бот ответит текстом
  и один раз в день предупредит об этом.

## Разработка

```bash
pip install pytest
python -m pytest -q
```

Структура:
- `bot/brain.py` — цикл Claude с инструментами, сборка контекста, учёт расходов;
- `bot/tools.py` — инструменты (схемы и исполнители);
- `bot/db.py` — SQLite и полнотекстовый поиск;
- `bot/scheduler.py` — напоминания, брифинги, ночное сжатие;
- `bot/handlers.py` — Telegram;
- `bot/voice.py` — речь;
- `bot/prompts.py` — промпты.
